Comment jouer

But

Développez votre village, traversez les quatre âges et détruisez les bâtiments et unités adverses — ou construisez une Merveille et défendez-la jusqu'à la fin de son compte à rebours.

Commandes tactiles

  • Toucher une de vos unités : la sélectionner. Double toucher : toutes celles du même type à l'écran.
  • Appui long puis glisser (ou bouton ⬚) : sélection par zone.
  • Unités sélectionnées : toucher le sol = déplacer, toucher un ennemi = attaquer, toucher une ressource = récolter (villageois), toucher une fondation = construire.
  • Glisser un doigt : déplacer la vue. Pincer : zoomer. Minicarte : aller directement à un endroit.
  • Construire : sélectionnez un villageois, choisissez un bâtiment, touchez la carte pour le placer puis ✔.
  • Appui sur un bouton : sa description s'affiche dans le panneau d'information. Appui long sur une unité à former : jusqu'à ×5. Touchez une unité de la file pour l'annuler.
  • Villageois sélectionnés : touchez un mouton pour le mener à la récolte, un dépôt pour y déposer leur charge. Appui long sur la minicarte : envoyer les unités sélectionnées.
  • Placement : glissez le bâtiment fantôme du doigt, puis ✔.

Souris et clavier

Clic gauche : sélection (glisser = rectangle, Maj+clic : ajouter/retirer). Clic droit : ordre. Molette : zoom. Flèches, bords de l'écran (ou ZQSD sans sélection) : défilement. Survol d'un bouton : description.

Boutons de commande : la lettre affichée dans leur coin (rangées AZER… / QSDF… sur un clavier AZERTY). Ctrl ou Alt+1-9 : créer un groupe, 1-9 : le rappeler (deux fois : centrer). . villageois inactif, H hôtel de ville, Espace dernière attaque, Suppr supprimer, Maj placer plusieurs bâtiments, Échap annuler / menu.

Économie

  • 4 ressources : 🍖 nourriture (moutons, baies, cerfs, fermes), 🪵 bois, 🪙 or, 🪨 pierre.
  • Les villageois rapportent leur charge au dépôt le plus proche : hôtel de ville (tout), camp de bûcherons (bois), camp minier (or, pierre), moulin (nourriture). Construisez les dépôts près des ressources !
  • Chaque maison donne +5 de population. Le moulin débloque les fermes, qui se ressèment automatiquement (60 bois).
  • Les moutons appartiennent à qui les trouve en premier.

Âges

Passez à l'âge suivant depuis l'hôtel de ville, après avoir construit deux bâtiments de l'âge en cours. Chaque âge débloque bâtiments, unités et améliorations.

Combat (pierre-feuille-ciseaux)

  • Lanciers ➜ cavalerie · Cavalerie ➜ archers · Archers ➜ infanterie · Tirailleurs ➜ archers.
  • Béliers et trébuchets ➜ bâtiments. Mangonneaux ➜ groupes serrés. Moines : soignent et convertissent.
  • Les villageois peuvent s'abriter dans l'hôtel de ville (🔔 cloche) : il tire alors davantage de flèches.

Multijoueur

« Créer une partie en ligne » donne un code et un lien à partager. Vos amis ouvrent le lien sur leur téléphone, choisissent leur nom et rejoignent. Le micro 🎙️ s'active et se coupe à tout moment ; 🔊 coupe le son des autres. L'hôte doit garder la page ouverte pendant toute la partie.
